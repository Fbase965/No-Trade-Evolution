# Guia de Instalação no Emulador (Citra / Lime3DS / Azahar)

Este guia explica como instalar e testar o mod nos emuladores de Nintendo 3DS no computador.

---

## 🎮 Instalação no Citra / Lime3DS

1. Abra o emulador **Citra** ou **Lime3DS**.
2. Na lista de jogos, localize **Pokémon X** ou **Pokémon Y**.
3. Clique com o **botão direito** em cima do jogo e selecione **"Open Mods Location"** (ou *"Abrir Local dos Mods"*).
4. Uma pasta com o Title ID do jogo será aberta no explorador de arquivos:
   * Pokémon X: `.../load/mods/0004000000055D00/`
   * Pokémon Y: `.../load/mods/0004000000055E00/`
5. Copie a pasta `romfs` de dentro de `Mod-Package/Citra_Lime3DS/Pokemon_X/` (ou `Pokemon_Y`) para dentro dessa pasta que se abriu.
6. A estrutura final deve ficar assim:
   `load/mods/0004000000055D00/romfs/a/0/1/8`
7. Feche e abra o jogo no emulador. O mod já estará ativo automaticamente!
